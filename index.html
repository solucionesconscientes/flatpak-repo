Easy Screen Recorder

Record your screen with GPU acceleration on Linux. Wayland and X11.

Install

flatpak install --user https://flatpak.solucionesconscientes.es/es.solucionesconscientes.EasyScreenRecorder.flatpakref

Updates come with flatpak update.

Needs gpu-screen-recorder installed on the host — it does the capture and is not bundled.
